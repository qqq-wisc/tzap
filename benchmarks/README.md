# Benchmarks

Circuits used to measure tzap. All are OpenQASM 2.0.

| corpus      | files | qubits | gates (total)      | gate set        |
| ----------- | ----- | ------ | ------------------ | --------------- |
| `feynman`   | 43    | 5–768  | 57–1.1M (2.46M)    | Clifford+T      |
| `cobble-t`  | 6     | 11–22  | 34k–588k (1.35M)   | Clifford+T      |
| `cobble-rz` | 6     | 11–22  | 1.9k–353k (793k)   | Clifford+T+Rz   |
| `qft`       | 4     | 20–50  | 310k–1.03M (2.68M) | Clifford+T      |
| `ftcircuitbench` | 63 | 4–200 | 23–2.1M (27.2M) | Clifford+T |
| `ftcircuitbench-large` | 32 | 9–128 | 478k–24.6M (210M) | Clifford+T |

## `ftcircuitbench`

Clifford+T circuits synthesized (Gridsynth, precision 5) from the inputs of
[FTCircuitBench](https://github.com/pnnl/FTCircuitBench): adders, Hamiltonian
simulation, HHL, QFT, QPE and QSVT. See
[`ftcircuitbench/README.md`](ftcircuitbench/README.md) for how it was built.
`ftcircuitbench-large` holds the other 32 inputs, the ones over 60,000
rotations, generated the same way (1.7 GB; regenerate rather than commit; see
[`ftcircuitbench-large/README.md`](ftcircuitbench-large/README.md)).

## `feynman`

The standard Feynman / T-par benchmark suite — arithmetic and reversible-logic
circuits (`adder`, `barenco_tof`, `gf2^N_mult`, `hwb`, `mod_adder`, `qcla`,
`tof`, `vbe_adder`, …) used across the T-count optimization literature. From
[meamy/feynman](https://github.com/meamy/feynman).

## `cobble-t` and `cobble-rz`

Block-encoding circuits generated by
[Cobble](https://github.com/charlesyuan314/cobble) ([arXiv:2511.01736](https://arxiv.org/abs/2511.01736)),
a compiler for quantum computational linear algebra.

Both directories hold the **same six programs** at two stages:

- `cobble-rz` — as Cobble emits them, with 122–910 un-synthesized `rz`
  rotations per circuit (2,198 total). The only Rz-bearing corpus here, so
  this is the one to use for gridsynth and Rz-placement work.
- `cobble-t` — the same circuits after Rz synthesis, Clifford+T only. Larger,
  since each rotation expands into an Rz-free sequence; the two-qubit structure
  is untouched (`cx` counts match pairwise across the two directories).

## `qft`

Large QFT instances from
[qqq-wisc/quantum-compiler-benchmark-circuits](https://github.com/qqq-wisc/quantum-compiler-benchmark-circuits),
the four with 100k+ gates. The name encodes qubit count and the generator's
depth parameter — `qft_q050_d87171` is 50 qubits — which is not the circuit
depth tzap reports (161,255 for that file).

| file              | qubits | gates     | T/Tdg   | cx    |
| ----------------- | ------ | --------- | ------- | ----- |
| `qft_q020_d32421` | 20     | 309,835   | 167,567 | 410   |
| `qft_q030_d50671` | 30     | 549,880   | 297,387 | 915   |
| `qft_q040_d68921` | 40     | 790,125   | 427,207 | 1,620 |
| `qft_q050_d87171` | 50     | 1,030,570 | 557,027 | 2,525 |

Unusually 1q-heavy — over half the gates are `t`/`tdg` and under 0.3% are `cx`,
where the reversible-logic circuits in `feynman` and the `jku_suite` run closer
to 1:1 T-to-`cx`. `tzap -O3` reduces T by 27.0–27.3% across all four, a spread
of 0.3 points over a 3.3x size range.
